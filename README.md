# study-tree · 学习树（项目功能备忘）

> 一句话：一个「能力 / 知识点」成长树单页应用，自带多用户、蓝图分享、好友和笔记。

## 一、这是什么

- 把自己要学的东西画成一棵「学习树」：**能力**（大方向）下面挂**知识点**（子节点）。
- 每个知识点有「时间成本」，点亮它消耗「科技点」；能力成本 = 所有子节点之和。
- 支持周常任务每周重置、前置依赖、等级经验，鼓励持续学习。

## 二、技术架构（零依赖）

| 文件 | 作用 |
|---|---|
| `server.js` | 后端服务，只用 Node 内置模块，`node server.js` 即跑 |
| `index.html` | 前端单页应用（画布、市场、资料等全部在这里） |
| `package.json` | 项目元信息 + 启动脚本 |
| `data/` | 全部数据（账号、学习树、笔记、蓝图、好友） |
| `Dockerfile` / `docker-compose.yml` | 容器化部署 |
| `启动.bat` | Windows 一键启动本地服务（0.0.0.0:5173） |
| `公网临时访问.bat` | 用 cloudflared 开临时公网隧道分享 |
| `安全上线清单.md` | 搬到公网服务器前的安全自查手册 |
| `使用说明.md` | 面向用户的功能使用文档（顶栏「? 说明」可看，首次注册自动打开） |
| `README.md` | 本文件（项目功能备忘） |

## 三、功能清单

### 账号与安全
- 注册 / 登录 / 登出，密码 scrypt 加盐哈希，httpOnly Cookie 会话
- 昵称、头像（可裁剪上传）
- **修改密码**：资料卡底部填旧密码 + 新密码，改完自动注销其他设备
- 会话 30 天过期，启动时和每小时自动清理过期会话
- 管理员应急重置：`node reset-password.js <用户名> <新密码>`
- 能力名全站唯一；历史重名可用 `node merge-duplicates.js` 合并（自动备份，`--dry` 可预览）
- 登录限速（防爆破）、静态文件白名单、CSP 等安全头
- **注册验证码**：一次性算术题（5 分钟有效、用过即废），配合同 IP 限速挡批量注册
- **CSP 用 nonce**：`script-src 'self' 'nonce-…'`，不再放开 `unsafe-inline`
- **搜索防枚举**：好友搜索必须 ≥2 个字符、最多 12 条、按人限频，不返回账号总数
- 检测到 HTTPS 时自动下发 `HSTS` 与 `X-Frame-Options: DENY`

### 学习树（核心）
- 三大基础分类（艺术 / 运动 / 学习），可增删分类
- 能力固定在左栏，画布可**拖拽 / 缩放**
- 知识点可点亮（消耗科技点）、可设前置依赖
- 能力成本 = 子节点之和，连线展示层级/前置关系
- 每个节点可写**学习记录**（描述）+ 最多 **3 张描述照片**（存 `data/users/<uid>/photos/`，点缩略图看大图）
- 周常任务每周自动重置；等级经验（点亮得经验）

### 时间规划 → 科技点（自动生成）
- 每天三个可安排时段：**08:00–12:00 / 12:00–17:00 / 19:00–22:00**，合计 12 小时
- **周视图课表**：周一到周日 7 列 × 08:00–22:00 时间轴，课程（实色块）和日常规划（虚框块）画在同一张表里
- 顶部显示当前周数和日期范围，`◀ ▶` 可切换上一周/下一周；今天那一列高亮
- **实时时间线**：一条红色横线标出「现在」，每秒钟移动；打开面板会自动滚到当前时间附近
- 点课表里的卡片可直接删除（课程/规划同一条目会一起移除）
- 添加课程时**可一次勾选多天**（如周一到周五一起加）；日常规划同样支持选天
- 重叠的课程/规划会自动合并，不会重复扣；不在三个时段内的时间不影响空闲
- 自己设**转化率**（0–100%，支持小数）：整周空闲时间 × 转化率 = 本周总量
  - 例：一天 12 小时空闲、转化率 50% → 6 个科技点；整周 84h × 100% = 84 点
- **整周一次性到账**：周一 00:00 把「整周空闲 × 转化率」全部记入余额，本周内只扣不增（任务奖励另加），下周一自动重置
- 顶栏显示「**当前可用 / 本周总量**」（如 `77 / 84`）；面板另有「距周结束」实时倒计时（每秒刷新）
- 点亮节点扣的是可用余额；周常任务奖励单独记账
- 转化率改一下，所有数字立即重算；以**自然周（周一起）**为周期，跨周自动重置

### 笔记
- 支持 md / pdf / txt / doc / docx / ppt / pptx / 图片
- md 可**在线编辑**，pdf/图片在线预览，Office 文档需下载后用本机 Word/WPS/PowerPoint 打开
- 笔记挂在具体节点下，按账号隔离
- **两种存储模式**（笔记面板底部可切换）：
  - 服务器模式（默认）：文件存在 `data/users/<uid>/notes/`
  - **本地模式**（Chrome / Edge）：选一个自己电脑上的文件夹，文件直接写进去，**服务器只存文件名/大小，不占服务器磁盘**；阅读、编辑、删除都直接操作本地文件

### 蓝图市场
- 把某个能力「发布成蓝图」，别人可一键导入
- 市场分类：运动 / 学习 / 艺术 / 其他 + **好友蓝图**筛选
- 蓝图可见性：**公开 / 仅好友 / 私人**
- 蓝图评分（标题/说明/节点/节点笔记/附件六维，0–100）
- **描述可配图**：最多 3 张，图片存服务器 `data/blueprints/<id>/images/`，市场卡片显示封面
- 本地笔记**不会打包进蓝图**（服务器没有文件内容），蓝图只带节点结构和描述配图
- 我的蓝图库：可改标题、说明、分类、可见性、配图，或「用当前学习树更新内容」

### 社交
- 好友：**申请 → 同意** 制
- 访客模式：只读查看好友的学习树
- 等级、个人资料卡

### 管理与反馈
- 管理员后台：查看/搜索账号、改角色、看任意人的学习树和蓝图
- 意见反馈：用户提交，管理员回复

## 四、快速启动

```bash
# 方式一：Windows 直接双击「启动.bat」
# 方式二：命令行
node server.js
# 然后浏览器打开 http://127.0.0.1:5173
```

首次注册的账号会自动成为管理员。数据都在 `data/` 目录，按账号隔离。

## 五、常用环境变量

| 变量 | 作用 |
|---|---|
| `PORT` / `HOST` | 监听端口 / 地址（默认 5173 / 0.0.0.0） |
| `TT_DATA_DIR` | 数据目录（默认 `./data`） |
| `TT_PUBLIC=1` | 公网严格模式（加 HSTS / Secure Cookie） |
| `TT_CLOSE_REGISTER=1` | 关闭自助注册 |
| `BP_MIN_SCORE` | 蓝图最低上架评分（默认 0 不拦截） |
| `NO_OPEN=1` | 启动后不自动开浏览器 |
